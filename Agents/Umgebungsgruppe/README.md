Folgende Änderungen an den Chatbot-Dateien wurden durchgeführt:
- Sprache auf Deutsch gestellt und Prompt auf Deutsch hinzugefügt
- Verbindung zu den Umweltdaten-APIs hinzugefügt (z.B. Wetter)
- Verbindung zu den APIs der Modelle hinzugefügt (Heatmap, Region Counting)
- Verbindung zu den APIs für Lautstärke und Helligkeit (Loudness, Brightness)

Folgende Informationen können zum Beispiel erfragt werden:
- Wetter
- Aktivitäten heute
- Datum, Uhrzeit, Feiertage
- Wie viele Menschen gerade an der Unterhaltung teilnehmen
- Wie hell/dunkel es gerade ist
- Welche Events heute in Karlsruhe stattfinden
